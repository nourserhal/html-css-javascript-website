- Home page design
- Login interface
- Registration pages
- Dashboard interface

- User-friendly UI design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

- HTML pages for website structure
- CSS files for styling and responsive design
- JavaScript for interactive functionality
